# vis.gl development tools

Shared development tools for building, testing, linting, bundling, and publishing vis.gl's open source JavaScript frameworks.

## Documentation

- [Dev tools](/docs/dev-tools) — build, test, lint, release, and migration guidance.
- [TypeScript plugins](/docs/ts-plugins/ts-transform-webgpu) — TypeScript transforms maintained by this repository.
- [Docusaurus Website](./docusaurus-website.md) — the shared documentation website package used by current vis.gl projects.

The documentation site is built with Docusaurus and the shared `@vis.gl/docusaurus-website` configuration.
