# Historical Gatsby documentation

Earlier versions of this project included a Gatsby theme named `gatsby-theme-ocular`. That theme and its website-specific documentation are no longer part of the repository.

Current vis.gl project sites use Docusaurus with `@vis.gl/docusaurus-website`. See the [Docusaurus Website guide](./docusaurus-website.md) for the current approach.
