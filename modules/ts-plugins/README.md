# @visgl/ts-plugins

Shared TypeScript plugins for vis.gl's open source Javascript frameworks

For documentation, see [https://github.com/visgl/dev-tools/tree/master/modules/ts-plugins/docs]

Standalone output transforms for native compiler builds are exported from `@vis.gl/ts-plugins/output-transforms`. See [ocular-build](../dev-tools/docs/cli/ocular-build.md) for consumer configuration and limitations.
